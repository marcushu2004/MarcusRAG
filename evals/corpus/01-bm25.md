# BM25 与稀疏检索

BM25 是一种基于词频的检索打分函数，属于稀疏检索（sparse retrieval）家族。它把查询中的每个词分别与文档匹配，再对结果加权求和，因此不需要把文本压缩成稠密向量，也不依赖 GPU。

## 打分公式

BM25 的经典形式由三部分组成：逆文档频率 IDF、词频饱和项和文档长度归一化项。单个查询词 q 对文档 d 的贡献可以写成：

  score(q, d) = IDF(q) * (tf * (k1 + 1)) / (tf + k1 * (1 - b + b * |d| / avgdl))

其中 tf 是词 q 在文档 d 中出现的次数，|d| 是文档长度，avgdl 是语料平均文档长度。

## 参数含义

- k1 控制词频饱和速度，取值通常在 1.2 到 2.0 之间。k1 越大，词频继续增加带来的收益衰减越慢；k1 越小，一个词出现两次以上就很快饱和。
- b 控制文档长度归一化的强度，取值范围是 0 到 1。b = 0 表示完全不做长度归一化，b = 1 表示完全归一化。默认值通常取 0.75。
- IDF 让罕见词的权重高于常见词，起到抑制停用词的作用。

## 分词与中文

BM25 依赖分词。英文可以用空格切分，中文没有天然空格，常见做法有两种：一是使用分词器（如 jieba）得到词语序列；二是使用字符二元组（bigram），把连续两个汉字作为一个词项。二元组不依赖词典、对未登录词更稳健，代价是词表变大。在混合检索系统里，中文语料常采用二元组切分，并保留英文与数字的整词形式。

## 局限

BM25 只匹配字面，无法处理同义改写。查询“如何降低延迟”无法命中只写了“减少响应时间”的段落。这正是需要用向量检索补齐的地方，也是混合检索的动机。
